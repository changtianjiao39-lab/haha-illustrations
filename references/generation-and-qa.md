# 生成提示词与逐张 QA

## 单张提示词骨架

把方括号换成当前文章的具体内容，每张单独生成。传入角色图、猫咪图和认可样图时，必须声明各图用途，防止复制样图原场景。

```text
生成一张 16:9 中文公众号正文配图。暖白纸面，彩色蜡笔手绘，轻微纸纹与断续颗粒，留白明显。
角色身份参考 assets/haha-character.png 和 assets/gray-cat.png；认同样图 assets/approved-editorial-example.png 仅参考叙事关系、轻微立体感和整体调性，不复刻工作台、Agent Space、文案和布局。
原文锚点：[原文段落或准确摘录]
唯一要表达的意思：[一句话]
HaHa 的核心动作：[动作]
灰猫的配合动作：[动作，与同一件事有关]
主物件与材料：[1 个主物件]
辅助场景：[最多 2–3 个，每个对应原文]
人物与猫咪之间的连接：[递送、视线、触碰、追随、共同路径等]
文字：[0–3 个短词，精确写出；没有必要时留空]
配色：HaHa 蓝黄、猫咪灰黄橙固定；暖纸白主背景，安全蓝与浅木棕做结构，铜橙只强调动作和阅读路径，少量低饱和绿。不能让主题色改变角色身份。
画法：纸板厚边、轻微侧面、遮挡与蓝色蜡笔接地影子形成温和体积；人物、猫咪、道具、箭头、文字共享同一蜡笔质感。
构图：先看 HaHa 与猫咪共同动作，再读主物件和次级场景。背景不铺满，禁止喧宾夺主。没有照片、3D、矢量图标、PPT 格子、大块深底、复杂 UI、过多箭头或装饰绿植。
```

## QA：逐项判断

1. **身份**：HaHa 发型、圆框眼镜、发箍、卫衣和两处 `HaHa`；灰猫深灰毛、黄眼、橙项圈、银铃铛；两者都是统一蜡笔画风。
2. **动作**：HaHa 与猫咪共同推动同一段意思；删去猫咪会损失一个发现、协助或反馈动作，而非只少一处装饰。
3. **文案**：主物件和每个辅助场景都能对应原文；没有未经原文或事实支持的功能、数字或品牌保证。
4. **层级**：视线先到双角色与核心动作；配角道具、箭头和背景只作解释；浅底留白明显。
5. **颜色**：身份色固定，场景以暖白、安全蓝、浅木棕、少量橙为主；无突兀高饱和背景。
6. **画法**：蜡笔颗粒、手绘不规则线、轻微 2.5D 体积统一；无照片或光滑矢量混贴。
7. **文字**：逐字核对中文标签、`HaHa` 和任何数值；不可读或错字需要修正。

## 迭代顺序

先修身份和文字错误，再修“人物 / 猫咪没有参与意义”，再删减喧宾夺主的背景、辅助站点和箭头，最后微调颜色与颗粒。用户只指出一个问题时，保留已被认可的其余要素，做局部编辑。保留每版文件供对比。

## 验证边界

静态文件检查证明 Skill 结构可读，触发案例只证明路由规则在测试文本上工作；认可样图只证明这一张效果得到用户认可。后续每张公众号图仍需实际生成、人工视觉检查与必要修改。
