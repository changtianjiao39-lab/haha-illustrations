# 用户认可插图的六方面拆解

观察对象：`assets/approved-editorial-example.png`。这是用户已明确表示喜欢的单张例图。以下是可复用的设计判断，不是对所有生成结果的验证。

## 1. 整体视觉风格

暖白纸面上的彩色蜡笔编辑插画。表达方法是“手作工作场景”，不是功能截图或正式信息图。物件有简化体积与粗细不完全一致的轮廓，填色保留纸纹。画面带一点幽默和可靠感，既可爱又能说明工作关系。

## 2. 图案搭配与双角色互动

HaHa 在中心装置上转动控制杆；灰猫叼着一张会话卡向中心靠近。两个动作都属于“把未完成的工作接进新空间”的同一叙事。沙漏是压力起点，Agent 小架、资料盒和双人桌是不同结果；橙色细箭头把分散小场景连成读图路线。未来可改变动作和物件，但要保留“一个主动作 + 一个宠物配合动作 + 少量有因果的辅助场景”。

## 3. 配色

人物的高饱和蓝卫衣与黄色 HaHa 字样是第一识别点；猫咪灰毛、金黄眼睛、橙色项圈是第二识别点。暖纸白承载大面积背景，浅木棕给纸盒、桌面和陈列架体积，安全蓝用于装置、投影阴影和连接，少量铜橙用于箭头、转折和注意点。绿植只作低饱和呼吸点。色板是角色优先、场景服从；不要把新主题色涂到衣服、眼镜、猫咪身上。颜色值是近似指导，不是从单张图提取的精确品牌标准。

## 4. 背景与主体

主体和辅助站点像摆在同一张纸上的“场景小岛”，四周没有通栏场景。奶油白底留出呼吸空间；少量蓝色蜡笔地面阴影给物件落脚感。背景本身不讲第二个故事，不画复杂建筑、满屏花叶、铺满地砖或大面积装饰纹样。留白是信息层级：先看 HaHa 与中心动作，再顺连接读辅助站点。

## 5. 辅助图案与立体感

沙漏、卡片盒、小架和桌子都与文案内容有功能关系。纸板厚边、浅侧面、遮挡、桌脚、抽屉、斜放的卡片与接地影子，形成轻微 2.5D 立体感；没有 3D 渲染高光或复杂透视。辅助图案数量服从可读性：单图一般 1 个主装置、2–3 个次级场景，避免“把功能清单全部画进去”。

## 6. 涂鸦质感

轮廓有轻微手绘抖动，色块内有白色纸纹空隙和蜡笔颗粒。蓝色接地阴影是松散的斜线涂抹，不是模糊投影；橙色箭头和注意线像一笔画出，线宽和间距不完全机械一致。保持颗粒、笔触和光影在人物、猫咪、道具、文字标签上统一。禁止光滑矢量、写实照片、塑料 3D、硬边渐变、PPT 图标混入。

## 可泛化与不可泛化

可泛化的是叙事语法、角色分工、浅背景、有限辅助场景、配色层级和蜡笔材质。不可泛化的是 Agent Space 名称、特定按钮、沙漏、会话卡、三只 Agent 玩偶或原图的左右位置。每篇新文案都要重新找它自己的“主动作”和实体隐喻。
